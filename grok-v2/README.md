# Bipolar 2.x — Diário de Humor (bipolar.app.br)

PWA em pt-BR para pessoas com transtorno bipolar registrarem humor por período (Manhã/Tarde/Noite),
com rede de apoio que só vê o que o paciente permitir. API-first (Laravel 13, `/api/v1`, OpenAPI 3.1).
